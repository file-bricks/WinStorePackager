Offline-Modus aktiv

Die App-Shell ist lokal zwischengespeichert. Sobald wieder eine Verbindung besteht, kannst du den Companion normal neu laden.

  • Bereits gespeicherte Formulardaten bleiben im Browser erhalten.
  • JSON-Export funktioniert weiterhin lokal im Browser.
  • Neue Dateien oder fremde URLs brauchen wieder eine Verbindung.

Für den normalen Start nutze python web_companion/serve_companion.py.
